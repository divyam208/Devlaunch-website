# DevLaunch 🚀

DevLaunch is a developer-focused website designed as a learning and growth platform for aspiring developers.

## 🌐 About the Project

DevLaunch provides a clean and modern interface for developers to explore learning-related content, roadmap information, features, pricing, and frequently asked questions.

This project was built from scratch to practice frontend development and improve my understanding of HTML, CSS, and JavaScript.

## ✨ Features

- Responsive navigation bar
- Modern landing page UI
- Features section
- Developer roadmap section
- Pricing section
- FAQ section
- Interactive JavaScript functionality
- Responsive design for different screen sizes
- Smooth visual effects and animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
